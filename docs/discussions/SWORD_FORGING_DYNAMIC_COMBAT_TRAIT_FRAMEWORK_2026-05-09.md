# 锻造词条与动态战斗适配框架

日期：2026-05-09

本文记录对锻造词条体系的一次重要修正：词条不应把武器设计成只服务某个固定战斗动机的工具，而应让同一套基础动作在动态战斗中以不同物理结构解决问题。

## 1. 核心问题

先前曾尝试从普通攻击的即时用途出发划分词条，例如：

- 弹反护身
- 近身清压
- 穿线点杀
- 破势开窗
- 爆发处决
- 铺压续航

这个方向有启发，但不能直接作为武器定位。原因是本项目的战斗动机变化很快：玩家可能在几秒内连续斩弹、处理贴脸敌人、补残血、接御剑、再转入剑阵。玩家不可能为每个即时动机切换武器，也不应该依赖系统自动读心替玩家变形。

因此，锻造词条的正确目标不是回答“这把剑主打哪个单一用途”，而是回答：

**当玩家用同一套输入处理动态战斗时，这把剑的身体结构让它以什么方式完成相同基础职责。**

## 2. 适合本项目的系统模型

本项目更适合采用：

**基础职责固定，物理偏向改变解法。**

普通攻击、御剑和剑阵都有各自不可被词条破坏的基础职责。

词条可以改变：

- 节奏
- 惯性
- 承诺感
- 攻击轮廓
- 剑气组织方式
- 反馈重点

词条不能改变：

- 玩家是否还能用普通攻击斩弹保命
- 玩家是否还能处理贴脸压力
- 玩家是否还能通过命中或弹反建立剑意
- 玩家是否还能通过御剑和剑阵处理核心战斗机制

如果某个词条让某把剑失去基础职责，它就不适合当前战斗系统。

## 3. 三层设计结构

### 3.1 基础职责层

所有剑都必须保留。

普通攻击基础职责：

- 斩弹保命
- 近身处理
- 命中或弹反回剑意
- 给御剑和剑阵创造节奏入口

御剑基础职责：

- 处理中远距离高价值目标
- 切 Silk 或机制线
- 制造输出窗口
- 作为日常循环里的主动消耗型输出位

剑阵基础职责：

- 保留 12 把飞剑的可见库存感
- 通过鼠标距离连续表达环阵、扇阵、贯穿阵
- 在强化窗口内兑现近中远三类持续输出职责

### 3.2 物理偏向层

词条主要落在这一层。

建议重新收敛为三条可读性更强的物理轴：

| 物理轴 | 两端 | 玩家感受到的差异 |
| --- | --- | --- |
| 剑重 | 轻灵 / 重势 | 轻快连续 vs 厚重承诺 |
| 剑形 | 长锋 / 阔刃 | 直线远刺 vs 宽面横扫 |
| 灵构 | 凝锋 / 分光 | 合成一刀 vs 拆成多刃 |

这三条轴都来自铸造物理属性，而不是抽象战斗职业：

- `轻灵 / 重势` 来自密度、厚度、重心和转动惯量。
- `长锋 / 阔刃` 来自剑身长度、宽度、刃面和刃压。
- `凝锋 / 分光` 来自灵槽走向、导灵集中度和分流结构。

### 3.3 判定保底层

表现形态可以大变，但核心判定必须保底。

尤其是普通攻击弹反：

- `长锋` 的伤害形态可以更细长，但斩弹不能随之变得不可靠。
- `阔刃` 可以让斩弹读感更自然，但不能让其他剑失去基本斩弹可信度。
- `凝锋` 可以合成一刀，但不能让玩家在弹幕压力下不敢按左键。
- `重势` 可以更慢，但必须用更强读感、击退、打击反馈或命中收益补回承诺成本。

实现上可以把普通攻击拆成：

| 判定 | 职责 | 是否随词条大变 |
| --- | --- | --- |
| deflect_shape | 斩弹、保命、回剑意 | 只允许小幅变化，必须保底 |
| damage_shape | 打敌人、补刀、破势 | 可以大幅体现长锋/阔刃/凝锋/分光 |
| vfx_shape | 玩家读形态和节奏 | 必须明显体现词条差异 |

这样可以让剑的形态变化足够大，同时不破坏左键作为弹反工具的可信度。

## 4. 词条轴的职责

### 4.1 轻灵 / 重势

这条轴决定同一个动作的时间质感。

`轻灵`：

- 起手更快
- 后摇更短
- 三段普攻衔接更密
- 御剑更贴鼠标、更适合连续追击
- 剑阵频率更高，单次压迫较轻

`重势`：

- 起手更有预备读感
- 命中反馈更重
- 后摇和承诺更明显
- 御剑更像压线蓄势
- 剑阵频率更低，但每次扫过更有重量

注意：重势不能只是变慢。玩家必须感觉它是“重”，不是“迟钝”。

### 4.2 长锋 / 阔刃

这条轴决定力量如何投射到空间。

`长锋`：

- 伤害形态更直、更远、更窄
- 普攻更像斜线贯穿或点刺拉线
- 御剑更强调穿线、切 Silk、点破关键目标
- 贯穿阵形态更清楚

`阔刃`：

- 伤害形态更宽、更近、更有刃面
- 普攻更像半月横扫或扇面压过去
- 近身清压和斩弹读感更自然
- 环阵和扇阵的覆盖形态更容易读

注意：长锋不应被设计成“难弹反的剑”。长锋改变的是伤害与表现轮廓，不是废掉斩弹职责。

### 4.3 凝锋 / 分光

这条轴决定剑气是一体化还是多线化。

`凝锋`：

- 把力量收束成一次明确爆点
- 普攻可以从三段表现压缩成一次极快、清楚的合刃斩
- 御剑和贯穿阵更像单线高质量切割
- 适合做命中停顿、空间裂线、短促闪断

`分光`：

- 主刃之后有副刃、残影或延迟补线
- 普攻不只是透明影子，而要有可读的“主刃先到，副刃后补”
- 御剑轨迹可以被延迟复刻
- 剑阵可以表现为多层、多线或并行刃幕

注意：凝锋和分光应该是最强形态差异轴。凝锋不能只是线条变窄，分光不能只是加透明残影。

## 5. 对旧 `出势 / 归锋` 的处理

`出势 / 归锋` 的问题在于它们本质是收益相位：出手强，或回收强。

这在御剑和剑阵回收动作中容易读，但在普通攻击里很难形成足够大的形态差异。普通攻击时间短，玩家很难稳定感知“第一段更强”或“收势更强”，除非做成夸张动画，否则容易退化为数值差。

因此建议：

- 不再把 `出势 / 归锋` 作为当前三条主形态轴之一。
- 可以保留为后续副属性、招式词缀或某些剑灵行为倾向。
- 当前主形态轴优先采用 `长锋 / 阔刃` 替代它们，保证普攻、御剑、剑阵都有可见的空间形态差异。

## 6. 后续验证标准

实现或画图时，应按以下问题验证：

1. 玩家不看词条名，能否从普攻轮廓看出长锋和阔刃不同？
2. 玩家不看数值，能否从节奏和命中反馈看出轻灵和重势不同？
3. 玩家能否一眼看出凝锋是一刀合刃，分光是多线补刃？
4. 长锋、凝锋、重势是否仍然保留普通攻击斩弹可信度？
5. 四把验证剑是否只是风格偏向不同，而不是有些剑失去基础战斗职责？
6. 剑阵连续变形和御剑操作语法是否仍由玩家输入主导，而不是由系统自动替玩家选形态？

## 7. 当前推荐方向

当前推荐的主轴为：

- `轻灵 / 重势`
- `长锋 / 阔刃`
- `凝锋 / 分光`

推荐先不要继续按旧 `轻灵 / 重势 + 出势 / 归锋 + 凝锋 / 分光` 做完整实现。

下一步更适合先做一版新的普通攻击形态验证：

- 所有剑保留可靠斩弹层。
- 用 `长锋 / 阔刃` 明确拉开伤害轮廓。
- 用 `凝锋 / 分光` 明确拉开剑气结构。
- 用 `轻灵 / 重势` 明确拉开节奏、停顿和命中反馈。

只有当普通攻击这套基础输入成立后，再把同一套词条逻辑扩展到御剑和剑阵。
