# 关卡 × Boss × 夺能 方向（V1）

> 2026-10-09 · 用户试玩「北冥」垂直切片后确认：**朝这个方向做**。
> 原型：`tools/web_demo/yujian_combat_proto.html` → 标题“关卡原型（灰盒）”。取代此前的肉鸽方向（历劫 v2 代码仍保留在 demo 里，不再是主线）。

## 一、核心结构

- **关卡制，不做肉鸽**。每关 = 飞行关卡段（练本关要考的技术）+ 终极 Boss。
- **夺能**：击败 Boss 获得与它相应 / 相似的能力。能力是**新的动作**（不是数值），并且要成为后续某关 / 某 Boss 的解法（洛克人弱点链、空洞骑士能力门、终焉之莉莉“击败即得其灵”）。
- **关卡顺序**：前两关线性教学，之后自选（洛克人式）。
- **能力使用**：有限槽位，进关前搭配（洛克人 / 只狼义手式）。
- **Boss 两类交替**：巨物 Boss（考飞行与走位，史诗感，如鲲）与剑修 Boss（人对人斗法，考精确操作，如墨影剑客）。剑修本身就是 Boss：打败重剑 / 飘逸 / 剑阵剑修，得到开山 / 惊鸿 / 星罗。

## 二、技术性：以飞行控制为核心

- 已有：鼠标转向、W/S 油门、**双击 W 爆冲**（无无敌，转向变钝）、**双击 S 急刹**（骤减速 + 转向翻倍，播横板刹停，可接回锋斩）、**尾流咬尾**、**剑势格**（HUD 可见，机动耗格，高速 / 咬尾 / 险 / 斩弹回格）、破空闪（唯一带无敌的防守）、险、斩弹、回锋斩、御剑。
- 原则：先打磨现有操作的组合，不急着加按键；新操作必须解决现有操作解决不了的问题、有时机或位置讲究、能和现有操作组合。
- 下一步可做的“不加按键”深化：完美急刹·让刀、速度即伤害、俯冲借势。

## 三、关卡新鲜感：六个灰盒方向的结论

| 方向 | 原型 | 用户结论 |
|---|---|---|
| 赶路 · 赛道 | 剑林峡谷 | 不错 |
| 天象 · 力场 | 天象战场 | 不错 |
| 地形 × 战斗动作 | 丝网开路 | 不错 |
| **巨兽即关卡** | **鲲** | **最好，“打 Boss 很有感觉”** |
| 世界形状 · 弧形地平线 | 浮空小世界 | 不错；**镜头旋转太晕 → 一律固定镜头** |
| 世界形状 · 星辰引力 | 周天星海 | 引力的感觉不错；“星引甩射”没被感知（触发条件看不见） |

建议的单关结构：赶路段（半赛道）→ 战场段 + 本关天象 / 地形母题 → Boss。可与境界飞升串成一条线：筑基 · 云海 → 金丹 · 浮空小世界 → 元婴 · 九天罡风 → 化神 · 周天星海。

## 四、镜头规则

- **普通关卡与普通战斗：默认镜头**（视野约 30 × 16 米，速度视野最多 1.35 倍）。默认人物大小是下限，关卡不得为看全地形而拉远。
- **巨物 Boss 战：双目标自动取景**，框住玩家与当前弱点，1 ~ 1.7 倍，镜头中心偏向 Boss 但人物始终留在画面中部。补偿：人物描边发光（贴合轮廓，不画圆环）、斩击剑光保持屏幕原大小。用户确认“这个 Boss 视角现在挺不错”。
- 镜头不旋转（世界形状可以弯，画面不转）。

## 五、垂直切片「北冥」

追鲲（礁石、浪柱、雷云、墨鸦）→ 鲲三阶段（①鳞眼轮流张开、鳃弹幕、尾扫、吞海吸力 ②怒：潜渊后破海 ③化而为鹏：扶摇狂风、羽刃、鹏心）→ 夺能「鲲鹏之力 · 吞海」（Q 按住吸子弹和小怪、松开喷破甲水弹，解锁后全模式可用）→ 试招（密集弹幕 + 墨甲卫）。

## 五（续）、第二关「剑冢」（2026-10-09）

验证 Boss 两类交替与能力链。剑林峡谷（残剑定时射剑气、中段“剑幕”：擦弹穿过 / 吞海吸掉 / 等空隙）→ 剑冢守灵「孤鸿」（人形剑修，默认镜头）：①斗剑（格挡反击、冲斩、剑气三连）②万剑归冢（剑罡 + 重剑雨；破罡 = 吞海重弹 / 斩回重剑 / 御剑）③人剑合一（三段连冲）→ 夺能「见招」（E：0.2 秒拆招窗口，弹回子弹 / 近身攻击者露破绽，按空 0.55 秒硬直）→ 试招（墨影剑客 ×2、蓄势针重针）。能力链：吞海在剑幕和剑罡阶段都有用武之地，但不是必需。
