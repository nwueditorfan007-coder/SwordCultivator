## 〇、设计北极星（2026-10-08 确认）

**动作的身体，决策的灵魂。** 保留即时飞行和斩击的手感（吸引人进来），让"想法"成为玩下去的动力（让人留下来）。

- 来源：用户自述玩不进 Jet Lancer / Hades，能玩进杀戮尖塔 / Fights in Tight Spaces，最上瘾的是"**尝试新思路**"：输了知道哪里错，下一局换个打法。
- 所以每个系统都要回答：**它能不能让玩家产生一个"下一局我想试试 X"的想法，并且能验证这个想法？**
  - 构筑效果**具体可算**（多一把剑、能挡重针），不写百分比
  - 联动/共鸣**提前可见**（剑谱里列出全部共鸣），玩家能朝一个想法去凑
  - 玩家对拿到什么**有掌控**：分叉路线、参悟升重、舍弃剑诀
  - 失败**可归因**：陨落时告诉你被什么、在什么情况下打死
  - 一局**够短**（约 12–15 分钟），试一个想法成本低
  - 敌人**意图可读**，时停是思考空间
- 修仙题材与此一致：修仙主角靠谋算、底牌、以弱胜强取胜，不靠手速。
- 提醒：作者口味 ≠ 全部目标玩家，手感层不能削弱。

## 一、现状盘点

### 1. 内容清单

| 层 | 现有内容 |
|---|---|
| 动词（玩家能做的事） | 鼠标转向飞行、W/S 油门、顺锋斩 / 冲锋斩 / 回锋斩、斩弹、破空闪 + 险、御剑点刺 / 连斩时停居合、剑阵自动派剑 |
| 敌人 | 墨鸦（追射）、扇傀（扇形弹）、穿云锥（冲刺）、墨甲卫（正面甲）、蓄势针（远程狙击）；Boss 千丝傀儡师（切丝 → 破绽） |
| 构筑 | 5 槽位；可换模块：环阵、贯穿阵、一剑分三、回环剑、穿锋、墨旋、残影补刀、乘势（共 8 个）+ 2 个本命（开山、惊鸿）+ 2 个道心 |
| 剑修 | 重剑·开山、飘逸·惊鸿、自由构筑 |
| 流程 | ①剧情模式：教程 8 课 → 6 波 → Boss → 自由模式 ②历劫：选剑修 → 5 关 → 每关后三选一（替换同槽位或调息回血）→ Boss → 结算 |
| 结算 | 用时、斩敌、最大居合、险、斩弹、断丝、受伤、评级（甲上～丙） |
| 表现 | 像素海天 + 云海 + 前景、水墨时停、书法笔锋斩击、像素 bloom、海面水花、全合成国风电子音乐、连斩音阶 |

### 2. 做得好的（要守住的）

- **动词质量很高**。斩、闪、险、居合每个都有清晰的输入、清晰的反馈，有招牌时刻（时停 → 咔 → 两半 → 轰）。这是绝大多数独立游戏 demo 达不到的。
- **剑修 = 身体结构不同**，而不是属性不同。重剑"迎着上"、飘逸"擦着过"，方向正确。
- **Boss 有机制**（切丝 → 破绽），而不是血厚。
- **画面氛围好**：晴空、海、云、水墨时停的反差，截图有记忆点。

### 3. 实际跑起来看到的

- 角色在画面中约 26px，敌人是黑色剪影 + 红眼，子弹是红色光球。**画面里最醒目的是敌人子弹**，不是主角，也不是剑。
- 战场是无限的天空 + 海面，没有地形和地标。敌人从画面外成群飞进来，清完进入下一关。
- 每一关的目标都是"清空余敌"。

## 二、诊断：到底缺了什么

> 你说"缺了点什么但说不出来"。结合成熟爆款的规律，我的判断是：
>
> **动词（怎么打）已经很好，但缺"打的意义"——变强的感觉、值得打的对手、有讲究的战场、为什么而战。**
>
> 玩家玩 10 分钟后，手感带来的新鲜感过去了，就需要这几样东西接力。目前接力棒是空的。

按"对玩家感受影响多大"排序：

### 缺口 1：没有"变强"（最可能就是你说不出来的那块）

修仙题材的核心爽点是**突破**：从弱到强，一次次质变。肉鸽的核心爽点也是**滚雪球**：Hades 的祝福叠加、Vampire Survivors 的满屏、Balatro 的倍率爆炸。

现在的历劫：
- 三选一是**替换**同槽位模块，而且**每个都带代价**。选完以后不是更强，是"换了一种打法"。
- 5 关打完，玩家和第 1 关强度差不多。没有"我起飞了"的时刻。
- 选卡时的心情是"权衡"，不是"想要"。爆款肉鸽选卡时的心情是"天哪这个和我手上那个能配！"

"模块改形态不改数值"的原则是对的（它让每次选择都有意义），但**做过头了**：不改数值 ≠ 不变强。变强可以是**更多、更大、更连锁**，不必是攻击力 +10%。

### 缺口 2：没有"对手感"

现在的敌人都是**功能单位**：会射弹、会冲刺、有甲。它们是题目，不是对手。
- 外形都是黑色剪影 + 红眼，彼此区分度靠形状细节，小屏读不清。
- 修仙题材里最燃的是**斗法**：和另一个修士你来我往。目前只有 Boss 有一点这种感觉。
- 敌人死得一样（墨溅、两半），不同敌人没有各自"被斩"的爽点。

### 缺口 3：战场没有"讲究"

天空 + 海是无限、均匀的空间。在哪里打都一样，所以**空间选择没有意义**：
- 没有可以利用的地形（绕山甩开、穿云隐身、贴海借浪）。
- 没有除"全杀"以外的目标（护送、追击、破阵眼、限时逃脱）。
- 飞行游戏的精髓之一是"利用空间"，这一层还空着。

### 缺口 4：没有"为什么而战"

没有世界观、没有角色、没有一句话的处境。千丝傀儡师是谁、为什么要打它、打完以后呢？哪怕一句话的语境，都能让同样的战斗显得有分量。

### 缺口 5：画面焦点不在主角

最亮、最红的是敌人子弹；主角 26px、偏暗。玩家的眼睛被弹幕拉走，"我在御剑"的身份感被稀释。

## 三、完善计划

**顺序原则：先补"缺的那块"，再修门槛，再扩内容，最后对外测试。** 每一步都先做小实验让你试玩判断，确认对了再做完整。

### 阶段 A：验证"缺的那块"（约 1–2 周）

做三个**小而快**的实验，你试玩后判断哪个最能填上那种"缺了点什么"的感觉。可以都要，也可以只留一两个。

- [ ] **A1 修仙成长实验**（设计稿：`docs/systems/XIUXIAN_PROGRESSION_SYSTEM_V1.md`；开局即筑基 → 金丹 → 元婴 → 化神）
  - 局内境界：击杀和险积累修为，满了**突破**（练气 → 筑基 → 金丹），每次突破是一个大场面（天雷、全屏慢放、剑阵扩编），并且**质变**一次（例如剑阵从 12 把变 24 把、御剑多一把分剑、回锋斩变成两圈）
  - 三选一从"替换"改为"**叠加 + 升级**"：同槽位可以叠第二个模块或把已有模块升一级；保留代价，但代价是"打法要求"，不是"变弱"
  - 加 2–3 组**联动**：两个模块同时在身上，会解锁一个额外效果（例如 环阵 + 残影补刀 = 闪避时环阵跟着残影走）
- [ ] **A2 对手实验**
  - 做一个**敌方剑修**精英："墨影剑客"。它也会闪、会冲锋斩、会举剑格挡，会和你对冲。打它像斗法，不像清怪
  - 给现有敌人**各自的死法和音色**（墨鸦被斩散成羽毛、扇傀扇面裂开、墨甲卫甲片崩飞）
- [ ] **A3 战场实验**
  - 做一张**有地形的关卡**：几座浮空山峰 + 一片云海。山可以绕、可以借来甩开追兵；云里敌人看不清你，你也看不清它们
  - 一个**非全杀目标**：例如"斩断三处阵眼"（阵眼被敌人护着，散在地图里），逼出空间选择

验收：你试玩后能说出"对，就是缺这个"。根据结果决定阶段 C 里扩写哪个方向。

### 阶段 B：画面焦点与身份（约 1 周，可与 A 并行）

- [ ] B1 主角更亮、更大（或战斗时相机略近）：剑光、衣袂的亮度高于敌弹
- [ ] B2 敌弹换成次一级的醒目度（形状清楚但不抢戏），敌人剪影区分度加大（颜色 / 轮廓 / 尺寸）
- [ ] B3 一句话的处境：开局一行字交代"为什么飞在这里"，Boss 前一句台词

验收：截图里第一眼看到的是主角和剑。

### 阶段 C：一局完整的历劫（约 2–3 周）

按阶段 A 的结论扩写，目标是一局 15 分钟左右、有起伏、有成长、有收尾：

- [ ] C1 关卡结构：普通关 / 精英关 / 事件关 / Boss，地图有分叉选择（例如"险路：奖励多"）
- [ ] C2 模块池扩到约 25 个，联动扩到 8–10 组，保证每局都能"成型"
- [ ] C3 第三位剑修（剑阵型），三位剑修的玩法差异明显
- [ ] C4 结算"证道录"：本局思路（构筑）、成型时刻、**死因回放**，给出"下次试试 X"的钩子
- [ ] C5 剑谱：全部剑诀、重数效果、共鸣提前可查，玩家能朝一个想法规划
- [ ] C6 敌人意图显示：每个敌人清楚显示下一招和时机

验收：你自己连续打 5 局，每局构筑都不一样，而且都想再开一局。

### 阶段 D：上手门槛（约 1 周）

- [ ] D1 前 60 秒只用鼠标 + 左键就能爽（油门 / 闪避延后出现）
- [ ] D2 教程改为边玩边解锁，不暂停、不弹窗
- [ ] D3 90 秒内必然出现一次御剑居合

验收：找 1–2 个身边的人看着玩，不用口头解释。

### 阶段 E：试玩反馈（之后）

- [ ] E1 埋点 + 结束问卷
- [ ] E2 发链接给 5 位以上路人
- [ ] E3 汇总报告，决定下一步（传播素材 / 商店页 / 继续改）

> 对外发布前必须解决：`models/` 是 JyGameRemake 的美术资产，需确认版权或换成自有主角。

## 四、执行纪律

- **小实验先行**：每个新方向先做最小可玩版本，你试玩确认再做完整。
- **范围冻结**：A–C 期间，与"缺的那块 / 一局历劫"无关的打磨都放进停车场。
- **回归保护**：改默认玩法前先跑 `tools/web_demo/tests/combat_regression.js`。
- **计划是活的**：每个实验结束后更新这份文档。
