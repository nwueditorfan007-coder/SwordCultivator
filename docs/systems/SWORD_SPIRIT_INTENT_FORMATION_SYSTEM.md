# 剑灵会意编阵系统设计草案

记录日期：2026-05-13

状态：方向设计 / 原型依据。本文是精简版，用于先把核心边界讨论清楚；若原型成立，再更新 `docs/decisions/PROJECT_DECISIONS.md`。

## 1. 核心判断

当前“距离控阵”的根本问题不是阈值不够顺，而是输入语义冲突：

> 鼠标距离同时表达“我要打哪里”和“我要用什么阵型”，会干扰精确瞄准。

剑灵系统的目标不是自动代打，也不是 FPS 化，而是把剑阵控制从：

```text
鼠标距离 -> 阵型
```

改成：

```text
玩家意图 + 战场压力 -> 出剑谱
```

一句话目标：

> 玩家负责瞄准、走位和出手时机；剑灵在玩家意图范围内理解战场，把环阵、扇阵、贯穿阵编成短出剑谱。

## 2. 新边界

旧文档里“剑灵不能替玩家选择阵型”的边界需要修正，但不能推翻成自动战斗。

仍然禁止：

- 全图自动索敌。
- 让玩家不需要瞄准、走位和判断时机。
- 黑箱判断，玩家看不懂为什么出这个阵。
- 替代右键御剑处理关键目标。
- 重写锻造形态。

允许：

- 在玩家意图域内编排环、扇、贯穿。
- 近身高压时插入护主环阵。
- 目标横向散布时选择扇阵。
- 目标成线或存在高价值目标时选择贯穿阵。
- 剑灵性格影响优先级和出剑倾向。

新的边界：

> 剑灵不能替玩家玩游戏，但可以在玩家意图域内替玩家编阵。

## 3. 三个核心概念

**剑意锚点**  
`mouse_world` 不再直接等于阵型距离，而是玩家当前剑意指向。它回答“玩家大概想打哪里”。

**意图域**  
剑灵只在意图域内判断，不全场自由最优解。意图域包括：玩家到鼠标方向的主走廊、鼠标附近目标、玩家近身护主半径、正在制造机制压力的目标。

**出剑谱**  
1 到 3 段的短队列，不是长自动连招。

```text
环阵护主 -> 贯穿远端目标
扇阵扫面 -> 贯穿高价值目标
环阵解压 -> 扇阵清场 -> 贯穿破线
```

很多时候一个清晰动作就够了，不需要强行排满三段。

## 4. 三阵职责

**环阵：护主**

- 由近身威胁触发，而不是由鼠标近距离触发。
- 处理贴身敌人、近身弹幕、低血压力。
- 读感：我看着远处，但剑灵知道身边危险，先护我一下。

**扇阵：扫面**

- 由目标横向散布触发，而不是由鼠标中距离触发。
- 处理一片中距离散怪、半包围和面压力。
- 读感：我往那边压剑，剑灵展开扇面扫掉那片压力。

**贯穿阵：破线**

- 由精确瞄准、高价值目标或纵向站位触发。
- 处理远端关键目标、成线敌人、Boss 开窗点等。
- 读感：我瞄准了那条线，剑灵把剑势收束成贯穿。

## 5. 首版规则

首版只做三个分数。

**护主分**

- 近身敌人越近越高。
- 敌人向玩家接近时提高。
- 玩家低血时提高。
- 如果玩家准星明确压住远端高价值目标，环阵只能短插一次，不能连续抢意图。

**扫面分**

- 主方向上目标横向散布越明显越高。
- 中距离普通敌人越多越高。
- 如果目标成线或存在高价值目标，贯穿优先。

**破线分**

- 准星压住高价值目标时提高。
- 主方向敌人成线时提高。
- 有 Silk、MirrorNeedler、Caster、Boss 开窗点等关键对象时提高。
- 不能无视高强度近身生存压力。

## 6. 露意反馈

剑灵必须“会意”，也必须“露意”。

玩家需要看懂剑灵判断：

- 环阵：近身威胁旁出现短促护主环影。
- 扇阵：目标区域出现淡扇面。
- 贯穿：目标线上出现细亮贯穿线。
- 出剑谱：飞剑或光标按环、扇、贯穿顺序短促脉冲。

玩家需要能纠偏：

- 松开左键取消。
- 移动鼠标改变剑意锚点。
- 右键御剑抢占关键目标。

## 7. 与现有系统的关系

**与御剑**

右键御剑仍然是玩家亲手处理关键目标、Silk、移动目标和精细路径的主操作。剑灵编阵只服务左键剑阵。

```text
御剑：我亲自出手
剑灵编阵：飞剑理解我，替我排阵
```

**与连续变形**

会意编阵不删除连续变形。阵型选择由出剑谱决定，阵型之间仍用连续变形过渡。鼠标距离可以影响当前阵型内部展开尺度，但不再负责跨形态选择。

**与锻造和剑灵性格**

继续保留旧原则：

> 锻造决定剑怎么动，剑灵决定它偏向怎么回应。

护主型更容易插入环阵；杀伐型更偏贯穿高价值目标；稳重型更偏扇阵整理战线；凝神型更尊重准星，不轻易被旁支目标带走。

## 8. 原型顺序

**P0：只显示判断**  
不改实际发射，只显示护主分、扫面分、破线分、推荐出剑谱和原因。

**P1：只做护主插入**  
左键剑阵时，如果近身威胁高，先短插环阵，再回到当前瞄准意图。

**P2：扫面 / 破线二选一**  
主方向横向散布多则扇阵；成线或高价值目标则贯穿阵。

**P3：短出剑谱**  
允许 1 到 3 段队列，例如环 -> 扇、环 -> 贯穿、扇 -> 贯穿、环 -> 扇 -> 贯穿。

**P4：剑灵性格**  
系统可信后，再加入护主型、杀伐型、稳重型、灵巧型、凝神型等倾向。

## 9. 验收问题

每轮测试只看这些问题：

- 玩家是否觉得剑灵在理解自己，而不是替自己玩？
- 玩家是否仍然需要瞄准、走位和选择开火时机？
- 环阵插入是可靠护主，还是打断远端意图？
- 扇阵和贯穿阵的选择能否从场上分布看懂？
- 露意反馈是否足够清楚？
- 出错时玩家能否纠偏？
- 御剑是否仍然有独立价值？
- 连续变形是否仍然是签名体验？

## 10. 成功标准

首版成功不是剑灵永远最优，而是：

- 玩家不再需要用鼠标距离拧阵型。
- 玩家能更专注于瞄准和战斗节奏。
- 剑灵判断大部分时间可预测。
- 偶尔误判时，玩家知道原因并能纠偏。
- 环、扇、贯穿职责更清楚，而不是变成黑箱自动攻击。

最终想要的感觉：

> 我没有少玩，反而更像在御剑。因为我不用手动拧阵型，飞剑能顺着我的剑意和战场压力自己成阵。
