## 1. 问题本质

当前原型的操作已经进入八向/航向输入语义，但动画如果仍像单一巡航循环，玩家会觉得角色“不听手”。问题不只是帧数不够，而是下面几件事没有在画面上说同一种话：

- 玩家输入的移动方向
- 人物身体朝向
- 脚下飞剑/隐形飞剑轴线
- 衣摆、发丝、飘带、气流的反向拖拽
- 转向时的重心、压身和惯性

御剑飞行的目标读感是：**人在控剑、压剑、借风转向**。不能像一张贴图被输入拖着走，也不能像飞机/导弹一样让整个人倒立翻滚。

## 2. 最终确认的视角规则

最终确认的视角不是纯横版平视，也不是 RPG 式正俯视八方向，而是：

**固定正交 2.5D 高机位摄像机 + 直立人物绕竖直轴旋转八个朝向。**

也就是说：

- 摄像机固定，不跟着方向转。
- 人物保持直立，不做飞机式 pitch 俯仰。
- 八向来自角色绕竖直轴每 `45°` 转一次。
- 左右不是镜像图，必须是同一个角色在固定相机下转到左侧/右侧后的独立视角。
- 刘海、马尾、衣摆、腰带、饰物等非对称细节必须保留在角色身体的真实物理侧。

方向规则如下：

| 编号 | 方向 | 画面读法 | 视角要求 |
|---|---|---|---|
| `01` | Right | 朝右侧向 | 相机更低、更接近平视侧面，保留横版飞行读感 |
| `02` | Up Right | 右上 | 更高的 2.5D 俯视背侧 3/4 |
| `03` | Up | 向上远离镜头 | 更高的 2.5D 俯视背面，能看到头顶、后脑、肩背和袍背 |
| `04` | Up Left | 左上 | 更高的 2.5D 俯视背侧 3/4 |
| `05` | Left | 朝左侧向 | 相机更低、更接近平视侧面，但不是 `01` 的镜像 |
| `06` | Down Left | 左下 | 更高的 2.5D 俯视正侧 3/4 |
| `07` | Down | 向下靠近镜头 | 更高的 2.5D 俯视正面，能看到头顶、脸/胸口、肩胸上表面 |
| `08` | Down Right | 右下 | 更高的 2.5D 俯视正侧 3/4 |

其中左右方向相机更低，上下和四个斜向更高。这一套参考图是后续 AI 生图、手绘修正和序列帧制作的视角真值。

## 3. 明确否定的错误方案

### 3.1 整张 sprite 跟航向旋转

这是最早被否定的方案。它会导致朝左飞时人物头朝下，玩家会读成失控翻滚，而不是御剑转向。

结论：**人物本体不能整张旋转 360°。**

### 3.2 人物永远直立但面向不跟航向

这个方案会出现“移动往左，但人物和剑还朝右”的倒飞。御剑飞行里，玩家必须相信角色朝向和移动方向是一致的。

结论：**移动方向、人物面向、隐形飞剑轴必须一致。**

### 3.3 四向镜像扩展成八向

这对非对称角色是原则性错误。角色有刘海、长发、衣服左右关系和配饰时，镜像会把角色身份翻反。

结论：**八个方向都应视为独立视角；镜像只能作为极早期占位，不能进入正式资产。**

### 3.4 一次性让 AI 生成整张八向图

这条路不可靠。AI 会把八向当成插画构图处理，容易镜像、乱补、错读 2.5D 相机。

结论：**正式生产应按单方向生成：母版角色锁身份，单张 3D 方向参考锁相机和朝向。**

## 4. 基础姿态与翻面/转向的区别

会话里讨论过 “roll / 翻面” 这个概念。最终结论是：

- 现在不需要先做完整 `roll` 动画表。
- 先做清楚 **八个方向的结果姿态**。
- 如果相邻方向视频补帧不自然，再补少量“转向压身中间帧”。

两者区别：

| 类型 | 解决的问题 | 示例 |
|---|---|---|
| 八方向基础姿态 | 角色已经朝某个方向飞时长什么样 | `right`、`up_right`、`up`、`down` |
| 翻面/压身过渡 | 从一个方向转到另一个方向时身体怎么扭、怎么压、怎么换面 | `right_to_up_right_mid`、`up_right_to_up_mid` |

当前阶段应优先完成：

`right -> up_right -> up -> up_left -> left -> down_left -> down -> down_right`

这些基础姿态。只有当 `right -> up_right`、`up_right -> up` 等相邻方向过渡在视频补帧里显得硬、飘或错面时，再补中间压身图。

## 5. 美术素材清单

最低可用版本：

- `cruise_8dir`：八方向定速巡航主循环。最优先。
- `idle_hover_8dir`：八方向悬停/低速浮动。每方向 `6-8` 帧即可。
- `boost_8dir`：高速巡航。可以先四向或五向占位，最终最好八向。

增强动作：

- `turn_bank_left`
- `turn_bank_right`
- `brake / drift`
- `dash_enter`
- `dash_exit`

视频转序列帧方案下，建议资产拆成两层理解：

1. **方向结果关键图**：8 张最干净、最稳定的人物姿态图。
2. **相邻方向过渡图/视频补帧**：根据关键图生成 `right -> up_right` 等过渡。

后续如果视频补帧质量不足，再补这些中间图：

- `right_to_up_right_mid`
- `up_right_to_up_mid`
- `up_to_up_left_mid`
- `left_to_down_left_mid`
- `down_left_to_down_mid`
- `down_to_down_right_mid`

不要一开始就做一张巨大的全动作表。先把关键方向做准，比堆过渡帧更重要。

## 6. 技术路线建议

### 推荐主路线：序列帧 + 分层 + 程序补表现

项目当前已经走序列帧管线，所以最稳的路线是继续用序列帧，但不要把所有表现烙死在一层。

推荐结构：

- 人物 body：八方向序列帧，保证朝向和姿态正确。
- 剑/隐形飞剑轴：可独立层或逻辑层，负责航向。
- 发丝/衣摆/飘带：可以随 body 序列帧画，也可以部分程序拖尾补充。
- 气流/残影：程序生成，永远朝速度反方向拖。
- 阴影：独立层，保持稳定，不跟人物乱转。
- 转向侧倾：程序给 body layer 加轻微角度、偏移和拉伸。

程序层只做小幅补充，不能代替八方向姿态本身。

### 不建议当前切 Spine

Spine 适合省帧、换装和骨骼微调，但这里的关键难点是 2.5D 八方向体积变化：正面、背面、侧面、3/4 背侧、3/4 正侧差异很大。用 Spine 做，最后仍然要大量替换皮肤和部件。

除非后续强需求是换装/纸娃娃，否则现在切 Spine 会打断管线。

### 3D 转 2D 的正确位置

3D 很适合做“视角真值”，尤其是：

- 固定正交 2.5D 摄像机。
- 同一角色模型按 `45°` yaw 旋转。
- 导出八张稳定参考。
- 帮 AI 或美术锁住相机、透视、左右非镜像和身体朝向。

但 3D 渲染不一定适合直接成为最终水墨角色图。更推荐：

`3D 参考图 -> AI/手绘风格化 -> 序列帧/视频补帧 -> Godot 接入`

## 7. AI 生图生产规则

正式生成八方向角色图时，应遵循：

1. 不要一次生成整张八向 sheet。
2. 每次只生成一个方向。
3. 每次同时使用：
   - 原始水墨人物模板图，用来锁身份。
   - 对应 `nanzhujue_8way_reference_from_model/<direction>.png`，用来锁相机和朝向。
4. 提示词必须写明：
   - `fixed orthographic 2.5D camera`
   - `character stays upright`
   - `rotates around vertical axis`
   - `do not mirror or flip`
   - `preserve asymmetrical details on true physical side`
5. 先生成候选图，用户确认后再进入 `accepted/`。

## 8. 运行时表现原则

运动和动画应分层：

- `target_heading`：玩家输入想要转到的方向。
- `body_heading`：人物/飞剑实际朝向，滞后追向目标。
- `velocity`：真实位移速度。
- `clip`：只负责“看起来是什么动作”，不能反过来锁死移动。

飞行自然感来自轻微滞后：

- 剑尖/飞剑轴可以先响应航向。
- 身体跟随目标航向，但不要瞬间跳。
- 衣摆、发丝、飘带永远落后速度方向。
- 急转时可以用 `100-150ms` 左右的压身/侧倾/拖尾延迟。

已有原型文档里也明确：clip 不驱动移动速度，真实位移由 `target_heading / body_heading / velocity` 决定。

## 9. 验收标准

玩家不看 UI，只看角色，应能在约 `0.2s` 内判断：

- 当前往哪个方向飞。
- 是平稳巡航、转向、加速还是减速。
- 人物是站在剑上控平衡，而不是普通悬浮、奔跑、滑翔或站姿展示。

单张方向图验收：

- 方向一眼读对。
- 左右不是镜像。
- 刘海、马尾、衣服左右关系不反。
- 上方向是俯视背面，不是平视背面。
- 下方向是俯视正面，不是平视正面。
- 斜上是俯视背侧 3/4。
- 斜下是俯视正侧 3/4。
- 左右相机更低，保留横版侧身读感。
- 人物姿势是御剑定速巡航：重心稳定、膝盖微屈、双脚沿隐形飞剑轴前后站位、手臂用于平衡。

过渡动画验收：

- 相邻方向切换不倒飞。
- 不出现整个人倒立。
- 不靠 clip 把玩家移动硬刹停。
- 衣摆/发丝/气流与速度方向相反。
- 急转有压身和惯性，但不抢控制。
