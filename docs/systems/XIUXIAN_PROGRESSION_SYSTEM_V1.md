# 修仙成长系统 V1：一局 = 一次证道（草案）

> 2026-10-08 · 对应 `docs/project/VIRAL_DEMO_PLAN.md` 阶段 A1
> 起因：用户试玩后觉得"缺少修仙的感觉"。诊断：动作手感很好，但缺**变强**，也缺修仙题材的核心语汇（境界、突破、天劫、功法、法宝）。
> 底层是现有的槽位框架（`COMBAT_FRAMEWORK_SLOT_DECOMPOSITION_V1.md`）：本系统只在它**上面**加一层修仙外衣和成长曲线，不推翻任何已验证的动作。

---

## 1. 体验目标（先说玩家感受）

1. **从凡到仙的弧线**：开局是刚筑基的弟子，踏剑而飞、一招斩；一局结束时剑如雨下、时停斩万物。玩家能清楚地说出"我比开局强了多少"。
2. **突破是全场为我停下的时刻**：天劫压顶 → 闪过天雷 → 金光冲天、书法大字"金丹" → 周围敌人被气浪震碎。这是一局里最值得录屏的瞬间。
3. **修炼的语言**：玩家想的是"再吸一点灵气就能突破了""这部功法再参悟一重，缺陷就没了"，而不是"冷却还剩 2 秒"。
4. **选择有期待**：机缘三选一时的心情是"这个和我手上那个能配"，不是"换了这个会失去什么"。

## 2. 修仙概念 → 游戏系统 对照

| 小说概念 | 在游戏里是什么 | 对应现有框架 | 玩家的感受 |
|---|---|---|---|
| **传承 / 师门** | 选剑修（重剑·开山、飘逸·惊鸿……） | 剑修 = 本命槽 + 身法手感 | "我是哪一脉的剑修" |
| **灵根 / 剑骨** | 剑修的身法手感（转向、惯性、闪避） | `BODY` 参数 | 天生的性格 |
| **修为 / 灵气** | 敌人死后化作灵气被吸入，积累修为 | 新增：修为条 | 每次击杀都在"修炼" |
| **境界** | 筑基 → 金丹 → 元婴 →（化神） | 新增：境界决定**根本能力** | 质变的台阶 |

| **剑诀（术法）** | 主动招式的形态：环阵、一剑分三、穿锋、残影…… | 现有 4 个槽位的形态模块 | 学新招、练深招 |

| **心魔** | （后续）用你自己的构筑化出的镜像对手 | 预留，对应计划 A2 | 斗法、自我超越 |
| **机缘 / 奇遇** | 关与关之间的三选一（以及后续的事件关） | 现有三选一 | 期待 |

## 3. 境界：根本能力的台阶

**原则**：境界给的是"**能做什么**"（质变），剑诀给的是"**怎么做**"（形态）。这样境界有分量，剑诀也不会被境界吃掉。

**贴合小说设定（2026-10-08 用户确认）**：修仙小说里通常**筑基才能御剑飞行**，而飞行是本作根基，所以**一局从筑基开始**。开场就是"筑基成功、第一次踏剑而起"，交代处境：刚筑基的弟子下山历劫。

| 境界 | 小说里的标志 | 游戏里的解锁 / 质变 | 主剑外观 | 预计到达 |
|---|---|---|---|---|
| **筑基** | 踏剑飞行 | 飞行、顺锋斩 / 回锋斩、斩弹、破空闪、险 | 灵剑，剑光淡 | 开局 |
| **金丹** | 剑气离体，飞剑取敌 | **御剑**（点刺、连斩时停）；剑阵 **6** 把 | 青色剑光 | 约 2 分钟 |
| **元婴** | 一心多用，分神驭剑 | 剑阵 **12** 把；收剑时万剑齐发；剑意上限提高 | 金色剑光，带剑鸣 | 约 7 分钟 |
| **化神**（Boss 战中 / 终局） | 领域 | **剑域**：一次性的大招，时停中全场万剑 | 剑化长虹 | Boss 低血时，作为终结技 |

- **脚下的剑和手中的剑分开**：筑基期踏着一把剑飞、用手中的剑斩；到金丹，手中的剑才能离手御剑。这与现有角色设定一致。
- 筑基只有最基本的动词，本身就是最自然的新手引导：**不需要单独的教程关**，学御剑正好发生在第一次突破之后。
- 剑修的本命招式开局就有（传承），不受境界限制。

## 4. 修为与渡劫

### 4.1 修为

- 敌人死后化作**灵气**（青白色光点），飞向主角被吸入。精英给更多，险给"顿悟"加成。
- 修为条满 → 出现提示"**瓶颈松动 · 按 F 引劫**"（按键可调）。

### 4.2 择时引劫（玩家的决定）

- 修为满后**由玩家决定什么时候渡劫**，不自动触发。
- 天雷**也会劈中附近的敌人**：在怪堆里引劫，雷能帮你清场，但躲雷更难。
- 拖着不渡也可以，但修为满了以后溢出的灵气就浪费了。

### 4.3 天雷小挑战（约 10 秒）

1. 天色骤暗，雷云在头顶聚集，音乐压低。
2. 落下 3 道（金丹）/ 5 道（元婴）天雷：先在落点出现预警圈，约 0.8 秒后劈下。
3. 用破空闪贴着天雷闪过 = **险**，额外给剑意，并让突破效果更好（"**道基完美**"）。
4. 被劈中：扣血，但**突破仍然成功**（"**根基不稳**"，少一点额外奖励）。不做"渡劫失败"，避免挫败感。
5. 最后一道雷落下 → **突破演出**：金光冲天、书法大字写出境界名、气浪震碎周围的普通敌人、音乐一个大的解决和弦。

## 5. 机缘三选一：从"替换"改为"成长"

关与关之间仍然是三选一，但卡片分三类：

| 卡片 | 效果 | 举例 |
|---|---|---|
| **新学剑诀** | 学会一个新形态，装进对应槽位（槽位已有剑诀时替换，旧的保留重数，可以换回来） | 学会《环阵》第一重 |
| **参悟升重** | 已有的剑诀或功法 +1 重（最多三重） | 《一剑分三》第二重：分光也斩精英 |
| **法宝** | 获得一件被动法宝（最多 3 件） | 紫金葫芦：每 8 秒收走身边一颗子弹 |

### 5.1 重数设计：代价随修为化解

现有每个模块都带"代价"。在修仙语境里，这正好是"**功法未圆满**"：

- **第一重**：现有效果 + 现有代价
- **第二重**：效果加强（更多、更大、更久）
- **第三重**：**代价化解**，或者效果质变

以现有 8 个剑诀举例（数值待调）：

| 剑诀 | 第二重 | 第三重（圆满） |
|---|---|---|
| 环阵 | 绕身 4 秒，剑数 +50% | 能挡重针（化解代价） |
| 贯穿阵 | 射程 +30%，三列齐射 | 微弱追踪（化解"不对准就白射"） |
| 一剑分三 | 分光也斩精英 | 一剑分五 |
| 回环剑 | 折返速度 +50% | 折返段也时停（化解代价） |
| 穿锋 | 剑气更宽、更远 | 剑气命中也给近身剑意（化解代价） |
| 墨旋 | 持续 2.5 秒、更大 | 回锋斩照常派阵剑（化解代价） |
| 残影补刀 | 补刀两次 | 不再增加破空冷却（化解代价） |
| 乘势 | 持续 2.5 秒 | 锁速期间转弯不受影响（化解代价） |

### 5.2 功法（心法）

剑意槽从"道心"扩展为"**主修功法**"，开局由剑修决定；路上可以参悟升重：

| 功法 | 第一重 | 第二重 | 第三重 |
|---|---|---|---|
| 重剑道心（开山一脉） | 贴身 +6，挡弹 +3 | 蓄满开山震出剑气 | 开山斩命中返还剑意 |
| 飘逸道心（惊鸿一脉） | 险给双倍剑意 | 险后瞬斩可连续两次 | 险触发短暂时缓 |

后续可以加"辅修功法"（第二个被动），作为扩展。

### 5.3 共鸣（联动）

两个特定的剑诀/功法同时在身上 → 卡片上显示"**共鸣**"，触发额外效果。Demo 先做 3 组：

| 共鸣 | 组合 | 效果 |
|---|---|---|
| **剑影随行** | 环阵 + 残影补刀 | 残影补刀时，环阵剑跟着残影走一遍 |
| **万剑归宗** | 一剑分三 + 贯穿阵 | 御剑收剑时，剑阵沿三道分光方向齐射 |
| **惊鸿照影** | 惊鸿（飘逸本命）+ 乘势 | 瞬斩后不减速，可以接冲锋斩 |

### 5.4 法宝（Demo 先做 3 件）

| 法宝 | 效果 | 取舍 |
|---|---|---|
| 紫金葫芦 | 每 8 秒自动收走身边最近的一颗敌弹 | 稳 |
| 护心镜 | 抵挡一次致命伤害，然后碎掉 | 保命 |
| 引雷符 | 渡劫时天雷 +2 道，但每道都会追着附近的敌人劈 | 激进：把天劫变武器 |

## 6. 修仙感的表现层（便宜但关键）

- **灵气吸收**：击杀后的光点飞入身体，带轻微的吸气音
- **境界名**：屏幕中央书法大字（复用现有书法字体）
- **天劫**：天色压暗、雷云、雷光照亮海面（复用光照预设系统）
- **本命飞剑换形**：剑光颜色和拖尾随境界变化
- **HUD 用修仙词**：气血 / 剑意 / **修为**；境界显示在左下角信息牌
- **结算改为"证道录"**：最高境界、渡劫评价（道基完美 / 根基不稳）、修成的剑诀和重数、共鸣

> 用词观察（待你定）："居合"偏日式剑客语汇，修仙语境可以考虑改叫"**心剑**""**一念斩**"或"**时停斩**"。

## 7. 一局的节奏（目标约 12–15 分钟）

```
开场：筑基成功、踏剑而起 ─ 第一关 ─ 机缘 ─ 第二关(修为满) ─ 引劫·金丹 ─ 机缘 ─ 第三关 ─ 机缘
  ─ 第四关(修为满) ─ 引劫·元婴 ─ 机缘 ─ 第五关 ─ 机缘 ─ 千丝傀儡师(低血时化神·剑域终结)
```

- 修为曲线按"第二关末、第四关末"各满一次设计；打得好（险多、无伤）会更早突破。
- 境界与关卡解耦：突破时机由修为决定，不是固定在某一关。

## 8. 实现切分（Demo 实验 A1 的最小版本）

按"先做最能验证感受的部分"排序：

1. **修为 + 灵气吸收 + 境界（筑基 / 金丹 / 元婴）+ 境界解锁能力**：验证"变强弧线"
2. **引劫 + 天雷小挑战 + 突破演出**：验证"最值得录屏的时刻"
3. **机缘卡改为 剑诀 / 升重 / 法宝**，8 个剑诀各做到第三重：验证"选择有期待"
4. **3 组共鸣 + 3 件法宝**
5. **表现层**：本命飞剑换形、HUD 用词、证道录

每做完一步，用户试玩一次再往下走。改默认玩法前跑回归测试；境界系统只在"历劫"流程中生效，剧情模式和自由模式暂时保持原样。
