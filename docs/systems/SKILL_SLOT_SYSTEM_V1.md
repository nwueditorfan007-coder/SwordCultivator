# 技能槽位系统 V1（夺能 = 改变槽位形态）

> 2026-10-09 用户定：招式系统**不能**“打败一个 Boss → 多一个新招式 → 多一个按键”。按键固定，夺能改变的是固定槽位里的**形态**。
> 2026-10-09 用户确认本文档（除第 5 条按用户修正改写）。
> 承接：`COMBAT_FRAMEWORK_SLOT_DECOMPOSITION_V1.md`（模块改形态不改数值）、`docs/project/LEVEL_BOSS_DIRECTION_V1.md`（关卡 × Boss × 夺能）。

## 一、八个槽位（不能再多）

每个槽位先定**战斗职责**。形态只改变“用什么方式完成这份职责”，职责本身不能丢。

| 槽位 | 输入 | 战斗职责 | 技术点 |
|---|---|---|---|
| 近战 | 点按左键 | 主输出 + 斩弹（处理迎面的子弹） | 出手时机、剑尖朝向 |
| 回锋斩 | 高速掉头 + 左键（急刹回身也算） | 解围：处理身后与包围 | 掉头时机 |
| 蓄力 | 长按左键 | 破防：破甲、破盾、高承诺爆发 | 蓄多久、敢不敢站住 |
| 主动技 | Q（有冷却，无消耗） | 改变局势：弹幕潮、聚怪、救急 | 什么时候交 |
| 被动技（剑阵） | 随动作自动 | 持续辅助输出 | 用什么动作去带它 |
| 御剑点刺 | 点按右键 | 远程精确处理：狙击、远处高价值目标 | 瞄准 |
| 御剑连斩 | 长按右键 | 时停居合：多目标兑现、切机制 | 路线规划、剑意管理 |
| 特殊天赋 | 无独立按键 | 让移动也能战斗：改变破空、爆冲、急刹、险等动作的副作用 | 用飞行技术打伤害 |

**移动不是槽位**：鼠标转向、W/S 油门、双击 W 爆冲、双击 S 急刹、空格破空闪、尾流咬尾、剑势格保持固定，所有剑修共用。天赋可以给它们加副作用。

**按键总表**（不再增加）：左键点按 / 长按、右键点按 / 长按、Q、空格、W/S（含双击）、F（引劫等情境键）。原型里的 E（见招）撤掉。

## 二、规则

1. **一槽一形态**，进关前搭配（关前“整剑”界面）。默认形态永远可用。
2. **每个形态 = 一个明显的好处 + 一个看得见的代价**，避免永远最优解。
3. **特殊天赋槽随境界增加**：筑基 1、金丹 2、元婴 3（上限 3）。
4. **获得来源**：Boss 夺能给**招牌形态**（有身份感、强）；普通形态从关卡挑战、隐藏要素、评级奖励获得。
5. **剑修是 Boss**：重剑、飘逸、剑阵等剑修作为 Boss 出现，打败得其**本命形态**。主角只有一个，不做开局选角色。**搭配的目的不是“修成某一路剑修”，而是针对每个 Boss 关卡的需要，自己搭出觉得合适的解法，成为自己手感玩得最好的剑修**（2026-10-09 用户修正）。
6. 形态之间的**共鸣**留到以后，V1 不做。

| 鲲（北冥） | 巨物 | 吞海 | 主动技 Q |

巨物 Boss 与剑修 Boss 交替出现；每个 Boss 的招牌形态，最好是后面某一关 / 某个 Boss 的解法（能力链）。

## 五、对现有原型的改动

1. 吞海保留在 Q，归为主动技的一种形态（Q 默认形态“剑鸣”待做）。
2. 见招改为**近战（点按左键）**的一种形态：每一刀出手瞬间就是拆招窗口（拆招是时机技术，必须即时输入，不能绑在长按上）；代价是剑弧更短；撤掉 E 键。
3. 新增**关前整剑界面**：八个槽位各选一个形态，天赋槽按境界开放。
4. 夺能结算改为“解锁某槽位的新形态”，并提示去整剑界面装上。
5. 现有模块按上表归位；历劫 v2 里的随机机缘、剑诀升重不再沿用。

## 五（续）、原型实现情况（2026-10-09）

`tools/web_demo/yujian_combat_proto.html`，搜索“整剑”。关卡原型（北冥、剑冢及六个灰盒关）里生效：
- 组合模块：左键（近战 / 回锋 / 蓄力）、右键（点刺 / 连斩）、身法（天赋）按整剑里选的形态分派。点按左键仍是按下立刻出刀，继续按住才进入蓄力 / 举剑。
- 已实现形态：近战 顺锋 / 穿锋 / 见招；回锋 整圈 / 墨旋；蓄力 开山；主动技 剑鸣（默认，冷却 10 秒）/ 吞海；剑阵 散星 / 环阵 / 贯穿阵 / 星罗；点刺 单剑 / 一剑分三 / 回环剑；连斩 单剑 / 分光；天赋 残影补刀 / 刹浪 / 冲阵 / 乘势 / 擦锋回势 / 惊鸿。
- 未实现：近战“连环”、回锋“回风”、蓄力“千里一线”、主动技“星引 / 雷引”、连斩“千丝”。
- E 键见招已撤掉，见招是近战形态（2026-10-09 用户：拆招必须即时，不能长按）。回锋斩之后按住可以接蓄力；开山蓄势转向放宽到 70%。夺能会解锁形态并直接替你装上。
- 整剑界面：选关卡片“整剑”、每关开局说明里的“整剑”；境界按钮决定天赋槽数（原型用，正式由境界决定）；“原型：解锁未做 Boss 的形态”开关。
