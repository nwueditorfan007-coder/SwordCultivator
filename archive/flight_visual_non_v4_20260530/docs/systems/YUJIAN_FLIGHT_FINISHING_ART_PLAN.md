# 御剑飞行成品化美术与技美打磨计划

- 日期：`2026-05-27`
- 状态：计划文档
- 范围：把当前 `YujianSpriteSequencePrototype` 从满意的飞行手感原型，推进到可作为正式方向验证的成品级飞行表现竖切
- 当前原型入口：`res://scenes/prototypes/YujianSpriteSequencePrototype.tscn`
- 当前主脚本：`res://scripts/prototypes/yujian_sprite_sequence_prototype.gd`
- 当前 V4 骨骼外观脚本：`res://scripts/prototypes/humanoid_8way_skeleton_visual.gd`
- 主要参考图：`G:/SwordCultivator/resources/flight/generated/yujian_v2_boost_enter.png`

## 1. 成品目标

玩家最后看到的不是“一个小骨骼人站在剑上飞”，而是一个小尺寸也能读清的修仙者正在御剑高速掠空。

成品级飞行效果需要同时成立四件事：

- 角色轮廓好看：长发、宽袖、袍摆、飘带和飞剑组成清楚的水墨剪影。
- 御剑关系可信：脚、剑、气光、身体重心读作同一个飞行系统，而不是角色被贴在剑上。
- 速度层级明确：低速、加速、高速、急转、冲刺爆发有不同的姿态和特效峰值。
- 战斗可读性不丢：角色再漂亮，也不能盖住敌人、弹幕、剑阵、碰撞反馈和玩家操作意图。

当前飞行手感已经较满意，后续成品化应优先保护运动模型和镜头舒适度。美术升级应围绕现有手感服务，不应重新大改输入和移动语义。

## 2. 当前问题判断

当前 V4 程序骨骼角色已经有“有型”的基础：它能表达御剑姿态、速度压身、四向主姿态和调参工作流。

但它还不够美观，根本原因不是缺少更多线条，而是角色仍然像“程序骨架外面挂了装饰”。成品感缺在：

- 主剪影不够强：袍摆、头发和袖子没有形成大块漂亮外轮廓。
- 灰阶层次不足：衣服内部缺少水墨明暗、折痕和体积。
- 部件主次不清：身体、衣服、飘带、剑气之间的视觉权重接近，容易散。
- 御剑接触弱：飞剑和脚底气光还没有成为角色力量来源。
- 动态层级不足：头发、袍摆、腰带、剑尾、气流还没有根据速度和转向形成有节奏的二级动态。

因此，不建议继续只在程序骨骼线上堆细节。更合理的方向是让当前骨骼继续负责控制和姿态，把最终观感转到分层水墨部件上。

## 3. 推荐技术路线

采用“骨骼控制器 + 水墨 PNG 部件 + 程序二级动态 + 克制粒子/VFX”的路线。

### 3.1 骨骼控制器

当前 `HumanoidEightWaySkeletonVisual` 的价值应保留：

- 接收真实飞行方向、速度、油门、boost、急转、carve 等运动参数。
- 继续维护低速和高速姿态。
- 继续支持四个主方向编辑，斜向由程序插值生成。
- 继续作为姿态调试、挂点调试、参数验证工具。

后续不应把 V4 骨骼绘制当作最终角色美术，而应把它升级为部件挂点和姿态控制层。

### 3.2 水墨 PNG 部件

角色主体使用透明 PNG 部件，而不是纯程序画线。推荐最小拆层：

- `head`：头部和脸部暗面
- `hair_bun`：发髻
- `hair_back_main`：后方主发束
- `hair_back_side_a/b`：侧向长发束
- `torso_robe`：躯干道袍主体
- `collar_front`：衣领和胸前亮边
- `sleeve_near` / `sleeve_far`：近侧和远侧大袖
- `robe_back_panel`：后方大袍摆
- `robe_front_panel`：前方袍片
- `sash_core`：腰带主体
- `sash_streamer_a/b`：腰带双飘带
- `leg_near` / `leg_far`：腿和靴
- `sword_body`：飞剑主体
- `sword_edge`：飞剑高亮边
- `foot_qi_contact`：脚底接触气光

这些部件应由 AI/手绘辅助生成，再人工清理透明边缘、锚点、灰阶和轮廓。程序绘制的衣服线条只保留为调试或低配回退。

### 3.3 程序二级动态

衣服主体不要用粒子系统承担。头发、袍摆、袖子、飘带应使用骨骼链或简化弹性节点，由速度和转向驱动：

- 速度越高，后发束、后袍摆和飘带越向反方向拉长。
- 急转时，外侧袖子和袍摆出现更明显的横向甩动。
- boost 进入时，部件先短暂压缩，再被高速拉开。
- 松油门时，部件回弹要慢、轻、克制，避免镜头之外再制造眩晕感。

二级动态的目标不是物理真实，而是形成漂亮、可信、稳定的御剑剪影。

### 3.4 粒子和 VFX 的职责

粒子系统只负责辅助，不负责衣服主体：

- 可用：剑尾气屑、风线、墨点、脚底气雾、冲刺残影、急转切风弧。
- 不建议：用粒子模拟袍子、长发、袖子、飘带的主要轮廓。

粒子层必须克制。平时只给速度感，冲刺和急转才给峰值。整场都很满会降低战斗可读性，也会稀释爆发瞬间。

## 4. 姿态与动作目标

先不要追求全 8 方向完整成品。应先把右向和左向做成能截图的高质量竖切，再扩展上下和斜向。

### 4.1 低速巡航

玩家感受：仙、稳、可控。

美术重点：

- 身体略立，重心在剑上方。
- 袍摆和发束轻轻后飘。
- 剑光淡，脚底气光稳定。
- 大袖保留道袍体面，不要过分张扬。

### 4.2 高速前压

玩家感受：锋、快、贴地掠空。

美术重点：

- 头、肩、胸向前压。
- 后袍摆成为最大的外轮廓。
- 头发和腰带飘带向后拉成长弧。
- 飞剑更亮，剑尾出现清晰拖尾。

### 4.3 急转侧压

玩家感受：御剑回锋，有劲但不晕。

美术重点：

- 身体向转向内侧压。
- 外侧袖子、袍摆、飘带被甩开。
- 屏幕上出现短促切风弧线。
- 镜头保持稳定，特效不要制造二次回弹感。

### 4.4 冲刺进入/爆发

玩家感受：催剑破空，瞬间变快。

美术重点：

- 角色短暂压缩，然后快速拉伸。
- 剑体和脚底气光短时增强。
- 出现 1 到 3 层克制残影。
- 墨痕和风线在尾部断裂，不要盖住角色正面。

## 5. V5 竖切原型建议

建议下一步新增一个 V5 表现分支，目标不是立即替换所有方向，而是验证“水墨部件版骨骼小人”是否能达到成品方向。

V5 最小范围：

- 只优先打磨右向和左向。
- 使用当前飞行手感、战场尺寸和镜头参数。
- 新增水墨部件挂点系统。
- 接入至少一套低速和一套高速部件姿态。
- 接入头发、后袍摆、腰带飘带的简化二级动态。
- 接入剑光、脚底气光、剑尾拖尾、急转切风、冲刺残影。
- 保留 F2/F4 调参能力，新增外观参数。

V5 不做：

- 不重写飞行输入。
- 不把粒子当衣服。
- 不一开始追全 8 方向最终质量。
- 不直接把参考图序列帧当作正式运行时资源。
- 不为了好看牺牲战斗可读性。

## 6. 参数面板需求

为了快速迭代，V5 应把关键视觉参数放入运行时面板。

角色部件：

- `角色整体缩放`
- `头部缩放`
- `后袍摆长度`
- `后袍摆宽度`
- `长发长度`
- `大袖宽度`
- `腰带飘带长度`
- `部件灰阶强度`
- `银灰描边强度`

二级动态：

- `发束随风强度`
- `袍摆随风强度`
- `飘带随风强度`
- `速度拉伸强度`
- `急转甩动强度`
- `回弹半衰期`
- `回弹最大幅度`

御剑 VFX：

- `剑体亮度`
- `剑尾拖尾长度`
- `剑尾拖尾透明度`
- `脚底气光强度`
- `常态风线密度`
- `高速风线密度`
- `急转切风强度`
- `冲刺残影数量`
- `冲刺残影间距`
- `墨点密度`

这些参数应能保存到 JSON，避免每次通过代码改数值。

## 7. 资源制作标准

### 7.1 部件美术标准

每个部件都应满足：

- 透明背景。
- 边缘干净，没有白边、黑边脏像素或抠图毛刺。
- 主轮廓清楚，内部灰阶不要碎。
- 大尺寸检查好看，小尺寸仍能读出形。
- 锚点清楚，挂到骨骼时不会漂。
- 左右镜像后不出现明显不合理的衣褶方向。

### 7.2 小尺寸读法

原型里的角色尺寸很小，成品部件应按游戏内尺寸检查，而不是只看原图。

优先级：

1. 轮廓是否好看。
2. 御剑关系是否清楚。
3. 速度方向是否清楚。
4. 头发、袍摆、袖子是否有层次。
5. 内部水墨纹理是否加分。

如果纹理漂亮但缩小后变脏，应减少内部细节，保留外轮廓和少量高光。

## 8. 验收标准

V5 竖切可以进入下一阶段的标准：

- 静止截图中，右向和左向高速御剑姿态明显比当前 V4 更好看。
- 小尺寸下能一眼看出长发、袍摆、宽袖、飞剑和脚底气光。
- 低速、高速、急转、冲刺的剪影差异明显。
- 常态飞行不吵，冲刺和急转有峰值。
- 角色在云海背景、敌人、弹幕和剑阵附近仍然可读。
- 松油门和急转时，衣服二级动态没有明显恶心的回弹。
- F2/F4 或新增面板能快速调整核心视觉参数。
- Headless Godot 启动无明显错误；视觉质量另需截图或编辑器实看确认。

## 9. 风险与边界

- 纯程序骨骼绘制很难达到参考图的完整美术完成度，最多适合做控制器、调试器和低配回退。
- AI 可以辅助出部件和风格方向，但不能自动保证多方向、多姿态、锚点和游戏内一致性。
- 8 方向同时开工会放大返工成本，应先证明右/左侧向高质量可行。
- 粒子堆多会让画面变吵，尤其会伤害战斗读图。
- 如果角色美术过分复杂，会和剑阵、敌人、命中特效争夺注意力。

## 10. 推荐里程碑

### M1：侧向水墨部件竖切

- 输出右向/左向的部件拆层。
- 接入骨骼挂点。
- 完成低速和高速两套剪影。
- 目标：截图明显更像修仙御剑角色。

当前已建立 V5 第一阶段原型入口：`res://scenes/prototypes/YujianSpriteSequenceV5Prototype.tscn`。这一版先用 `res://scripts/prototypes/yujian_ink_part_visual.gd` 的程序化水墨部件模拟最终拆层和二级动态，验证游戏内尺寸的长发、后袍摆、宽袖、腰带飘带、飞剑接触光和风线读法。后续如果方向成立，再把这些程序部件替换为手绘/AI 清理后的透明 PNG 部件。

### M2：二级动态

- 接入发束、后袍摆、腰带飘带动态。
- 用速度、boost、turn、carve 驱动动态强度。
- 控制回弹，避免晕感。

### M3：御剑 VFX

- 接入剑体高亮、脚底气光、剑尾拖尾、风线、急转切风、冲刺残影。
- 做常态/高速/急转/冲刺四档视觉强度。

### M4：方向扩展

- 把侧向成功经验扩到上、下和斜向。
- 继续保持四主方向编辑、斜向插值的工作流。
- 检查多方向的角色身份和体积一致性。

### M5：实战读图验证

- 放入敌人、弹幕、剑阵、云海背景中测试。
- 判断是否漂亮、清楚、不晕、不抢戏。
- 通过后再考虑进入正式资源管线或 Spine/序列帧生产。

## 11. 下一步建议

下一步可以直接开 `V5 水墨部件御剑角色` 小竖切：

- 先不替换当前满意的飞行原型。
- 在现有原型中新增一个可切换角色集。
- 用当前 V4 骨骼姿态作为挂点源。
- 先做右向和左向的高速飞行截图质量。
- 成功后再扩展到完整 8 方向与正式资源管线。

这条路线的判断标准很简单：如果 V5 右/左侧向在游戏内尺寸下已经明显比当前 V4 好看，并且不破坏飞行手感，就继续投入；如果仍然像程序小人，就应尽早转向更完整的 Spine 或序列帧方案。
