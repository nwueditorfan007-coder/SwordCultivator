# 御剑人物 Body 全量重绘任务包 V13

## Summary

V13 是一次完整重绘任务，不再以 V9/V10/V11/V12 的旧序列帧作为最终动作来源。

这次要解决的核心问题不是单个动作不好看，而是不同动作之间人物比例、头部大小、肩宽、腰带位置、袖口形状、披帛长度不一致，导致运行时切换时像在换人。

V13 的目标：

- 所有 body 动作全部基于同一张新母版和同一套比例规则重绘。
- 每条动作从 8 帧升级到 16 帧。
- 状态动作更稳，过渡动作更顺，释放动作更可读。
- 运行时仍保持“持续状态 + 一次性动作 + 过渡动作”的结构。
- 本轮只做人物 body，不画手持剑、不画御剑平台、不画完整剑阵、不画大型 VFX。

旧素材只能作为语义参考：可以看它们代表什么动作，但不能直接拼入 V13 最终图集。

## Why Full Redraw

当前旧序列帧存在这些问题：

- 不同动作里的头部大小不一致。
- 同一角色在 `idle / forward / back / parry / array` 之间肩宽和身体厚度变化明显。
- 腰带高度、袖口颜色、披帛形状会漂移。
- 部分动作像是从不同生成批次里抽出来，状态机一切换就露馅。
- 8 帧不足以表达“准备、运动、峰值、回收、落点”，尤其是阵型切换和释放。

因此 V13 不能继续靠抽帧和拼接解决，必须先锁角色比例，再全量重绘所有动作。

## Character Art Direction

V13 的角色不能是抽象符号、图标、小人剪影或只有轮廓的简化标记。目标是“元素像素风横版角色人物”，也就是缩小后仍然读得出是一个有服装、有发型、有身体结构、有修仙气质的可操作角色。

### Target Style

- 类型：横版动作游戏用像素风角色 sprite，不是 UI 图标，不是法术符号，不是 logo。
- 人物层级：必须是完整人物角色，有头、颈、肩、躯干、腰带、双臂、双腿、袖袍、披帛和头发。
- 像素质感：清晰像素边缘，有限色板，硬边块面，少量手绘像素高光。不要柔光糊边、不要厚涂、不要写实油画笔触。
- 立绘气质：冷峻、克制、仙侠、轻盈。像一个真实可操控的横版角色，而不是抽象的蓝色能量符号。
- 体型：年轻成年剑修，清瘦修长但有力量感。不是儿童，不是 Q 版，不是二头身或三头身。
- 读图优先级：第一眼要能看到“深青黑长袍人物”，第二眼看到“古金腰带和袖口”，第三眼看到“青蓝披帛和束发”。

### Required Visual Elements

每个动作、每一帧都必须保留这些元素：

- 黑发束起，有明确发髻或束发轮廓，不能变成无发光头或抽象帽子。
- 脸部小而克制，可以低细节，但必须有头脸结构，不能只有一个点或面具符号。
- 深青黑外袍是主轮廓，衣摆和袖袍形成修仙长袍剪影。
- 冷白内衫在领口、胸前或衣摆处可见，用来区分衣服层次。
- 古金腰带必须稳定存在，是人物比例锚点。
- 古金袖口必须稳定存在，是手臂动作锚点。
- 冷白青蓝披帛必须稳定存在，作为风动和仙气元素，但不能变成大面积特效。
- 双腿必须存在，forward/back 要能看到双腿岔开的姿态。

### Forbidden Visual Failures

以下结果必须退回重画：

- 人物变成蓝色火焰、符号、抽象剪影、能量团。
- 看不出衣服层次，只剩一团深色形状。
- 看不出头发、腰带、袖口、披帛。
- 角色像图标、贴纸、法术标记，而不是横版游戏人物。
- 过度柔化、发光、厚涂，像插画缩小而不是像素角色。
- 服装每条动作都不同，像不同角色。
- 脸、头、肩、腰带在动作之间漂移。

## Main Action Specs

### 1. idle

用途：普通御剑悬停，无剑阵、无控剑。

16 帧节奏：

- 1-4：基准悬停，轻微吸气。
- 5-8：袖袍和披帛微微上浮。
- 9-12：呼气回落。
- 13-16：回到第1帧附近，闭环。

要求：身体高度约 `166-170px`，行内高度变化不超过 `2px`。

### 2. forward

用途：向前推进。必须看到双腿岔开和弓步前倾。

16 帧节奏：

- 1-4：从稳定双腿站立进入前倾。
- 5-8：前脚压住、后腿撑开，弓步最明确。
- 9-12：保持前倾推进，袖袍和披帛向后拉。
- 13-16：回到可循环的前倾推进姿态。

要求：视觉高度约 `145-155px`。不要趴伏，不要变成飞扑。双腿分开必须清楚。

### 3. back

用途：后退/制动。必须看到双腿岔开和向后倒的重心。

16 帧节奏：

- 1-4：双腿稳定站立，重心开始后撤。
- 5-8：身体向后仰，前腿撑住，后腿压住。
- 9-12：维持制动姿态，披帛略向前浮。
- 13-16：回到可循环的后退制动姿态。

要求：视觉高度约 `150-160px`。不要坐下，不要摔倒，不要整体缩小。

### 4. parry

用途：普通攻击/弹反 body 动作。短动作，但必须有清楚起手、爆发、收势。

16 帧节奏：

- 1-3：战斗准备，肩线压低。
- 4-6：手臂和袖袍开始挥出。
- 7-9：弹反爆发峰值，动作最清楚。
- 10-12：力量通过，身体跟随。
- 13-16：自然收势，回到战斗姿态。

要求：不要画剑本体，body 动作要能支撑外部武器/VFX。

### 5. sword_control_idle

用途：右键御剑持续控剑状态，不是拔剑，不是出招。

16 帧节奏：

- 1-3：稳定控剑手诀，身体略向前，双脚和下盘保持稳。
- 4-6：前手向右前方推出半臂距离，后手在胸前牵引，肩线明显打开。
- 7-9：控剑气息峰值，前臂最远，袖袍和披帛向后扬起，身体只允许轻微前压。
- 10-12：前手画小弧回收，后手接住气机，袖袍开始回落。
- 13-15：回到稳定控剑姿态，披帛继续慢摆。
- 16：接近第1帧，闭环。

要求：这是“持续远控飞剑”的循环动作，动作幅度要比普通 idle 明显。手臂前后位移约 `10-18px`，袖袍和披帛摆幅约 `8-14px`，肩线有可见开合。头部大小不变，锚点不动，下盘不要跳。不要变成拔剑、挥剑或释放爆发。

要求：要和环阵明显不同。胸口打开，读作中距离扇面控制。

### 8. array_pierce_idle

用途：贯穿阵持续状态。单指凝线、远距离破线。

16 帧节奏：

- 1-4：单指凝线基准。
- 5-8：指尖轻微前探。
- 9-12：肩线稳定，披帛后浮。
- 13-16：回到第1帧附近，闭环。

要求：要和扇阵明显不同。不要双臂打开，重点是线性指向。

### 9. array_ring_release

用途：从环阵怀抱守圆推出一次近身护体脉冲，然后回到环阵。

16 帧节奏：

- 1-3：接近 `array_ring_idle`。
- 4-6：怀抱收紧蓄力。
- 7-10：双臂向外推出，释放峰值。
- 11-13：力量通过，袖袍回摆。
- 14-16：回到 `array_ring_idle`。

### 10. array_fan_release

用途：从扇阵控面推出一次扇面清场脉冲，然后回到扇阵。

16 帧节奏：

- 1-3：接近 `array_fan_idle`。
- 4-6：双手略收，准备推面。
- 7-10：双臂外推，扇面释放峰值。
- 11-13：力量通过，袖袍后摆。
- 14-16：回到 `array_fan_idle`。

### 11. array_pierce_release

用途：从贯穿阵指向凝线刺出一次贯穿脉冲，然后回到贯穿阵。

16 帧节奏：

- 1-3：接近 `array_pierce_idle`。
- 4-6：指尖微收，肩线蓄力。
- 7-10：向前贯穿释放峰值。
- 11-13：力量穿出，身体回稳。
- 14-16：回到 `array_pierce_idle`。

## Transition Specs

每条过渡都是 16 帧：

- 1-3：来源状态。
- 4-6：离开来源姿态。
- 7-10：中间转换。
- 11-13：接近目标姿态。
- 14-16：落到目标状态。

## Proportion Lock Rules

拼图线程和验收线程必须检查这些点：

- 头部高度：所有主动作和过渡帧之间变化不超过 `1px`。
- 腰带高度：相同姿态下腰带位置变化不超过 `2px`。
- 肩宽：非大幅动作状态中变化不超过 `2px`。
- 披帛长度：不能一条动作长、一条动作短。
- 袖口颜色：必须保持古金色，不允许漂成白色、蓝色或黑色。
- 脸部：所有动作都必须读作同一个人。
- 锚点：可见 body 底部接近 `y=219`。
- 不允许用整体缩放制造 forward/back 高度差。

## Runtime Integration Requirements

V13 需要把运行时从 8 帧升级为 16 帧。

推荐代码调整：

- `FlightRiderSpriteFx.DEFAULT_BODY_SHEET` 指向 `flight_rider_body_v13_sheet.png`。
- `FlightRiderSpriteFx.DEFAULT_BODY_TRANSITION_SHEET` 指向 `flight_rider_body_v13_transitions.png`。
- `DEFAULT_FRAME_COUNT := 16`。
- `frame_count` 默认值改为 16。
- `BODY_ACTION_ROWS` 行名和顺序不变。
- `BODY_TRANSITION_ROWS` 行名和顺序不变。
- 场景中 `FlightRiderSpriteFx.frame_count` 设置为 16。
- 图集读取逻辑仍按 `frame_size.x * frame_index` 和 `row * frame_size.y`。

推荐播放参数：

- `idle_animation_fps`: `8-10`
- `motion_animation_fps`: `14-18`
- `sword_control_idle_animation_fps`: `3-4`
- `array_idle_animation_fps`: `2-3`
- 阵型过渡时长：`0.55-0.70s`
- release 时长：`0.50-0.65s`
- parry body 表现时长：`0.32-0.42s`

注意：16 帧不是为了让持续状态动作变大，而是为了让慢呼吸更稳、让切换有中间过程。

## Acceptance Criteria

### Asset Validation

- 主图集尺寸必须是 `4096 x 2816`。
- 过渡图集尺寸必须是 `4096 x 3584`。
- 每格必须是 `256 x 256`。
- 所有帧最终必须透明。
- 不允许任何文字、编号、网格线、水印留在图里。
- 所有行都必须是同一个人物比例。

### In-Game Validation

- `idle / forward / back` 切换时不能像换人物。
- 普通攻击 `parry` 能看清，不是一闪。
- 右键御剑持续状态是慢速控剑呼吸，不闪。
- 环阵常驻是怀抱守圆。
- 扇阵常驻是双臂展开控面。
- 贯穿阵常驻是单指凝线。
- 阵型切换必须读作姿态转换，而不是硬切。
- release 播放后必须自然回到当前阵型 idle。

### Redraw Gate

以下情况必须退回重绘：

- 动作好看但角色比例变了。
- 单帧很漂亮但 16 帧连起来抖。
- 第1帧和第16帧无法闭环。
- forward/back 用整体缩放而不是腿部姿态表现。
- 三个阵型 idle 看起来像同一种动作。
- release 变成大特效，body 动作反而看不清。
